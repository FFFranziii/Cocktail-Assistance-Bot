# Cocktail-Assistance-Bot
Assistance Chatbot to decide for a Cocktail depending on one or more given ingredients

Starten des Chatbots
1. Venv aktivieren
2. In den Cocktailchatbot Ordner wechseln
3. rasa run Actions ausführen
4. In einem anderen Terminal Node-Red starten in dem node-red getippt wird
5. In einem anderen Terminal mit rasa Shell die Kommunikation starten
